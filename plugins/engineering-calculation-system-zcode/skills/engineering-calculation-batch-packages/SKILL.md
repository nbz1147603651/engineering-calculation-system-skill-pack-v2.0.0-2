# Engineering Calculation Batch Packages

Use this ZCode entrypoint for lifecycle skill 12c of the Engineering Calculation
System plugin.

1. Read `../engineering-calculation-system/SKILL.md` for the canonical package
   contract and ZCode adapter.
2. Read `../engineering-calculation-system/skills/12c-batch-import-export-packages.skill.md`.
3. Build managed import/export packages, manifests, saved normalized inputs,
   saved BookResult JSON, CLI/API batch execution, and batch summaries.
4. Keep package and batch artifacts in the active ZCode workspace, not in the
   plugin package.
