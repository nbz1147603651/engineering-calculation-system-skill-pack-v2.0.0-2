# Engineering Calculation Reusable Modules

Use this ZCode entrypoint for lifecycle skill 10 of the Engineering Calculation
System plugin.

1. Read `../engineering-calculation-system/SKILL.md` for the canonical package
   contract and ZCode adapter.
2. Read `../engineering-calculation-system/skills/10-reusable-calculation-modules.skill.md`.
3. Implement source-backed modules with typed inputs/outputs, stable public
   functions, formula traces, lookup behavior, warnings, and tests.
4. Keep module code and tests in the active ZCode workspace, not in the plugin
   package.
